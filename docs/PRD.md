## 0. 愿景、边界和优先级

构建一款美观、轻量、可调尺寸的 Windows 桌面日历/计划/时间记录小组件。两页：**月历+每日待办+每日实际日程记录**；**一周实际日程记录+周计划/周总结**。深色半透明圆角，清晰、易用、不拥挤；无常驻独立便签栏、无 Windows 默认白色外框。用户数据本地优先；不需账号、不做云同步、不发个人数据。

原则：待办（打算做）≠日程（实际做了）；日程可以关联未完成待办；复杂功能使用编辑弹窗、详情浮层逐步展开；默认即时保存，支持撤销；提供中英文界面（中文简体/English），**农历日期保持中文**。

产品定位：默认融入 Windows 桌面，类似壁纸组件，长期位于普通应用下方；桌面层行为是核心体验，不是普通悬浮窗口的附加装饰。最高优先级为已确认交互语义、视觉简洁、数据可靠、无白框透明窗口及完整中英文切换。所有条款都必须进入最终范围，不能悄悄省略；先技术验收，再分阶段交付。

## 1. 术语与数据模型（逻辑模型，不强制实际类名）

- `Todo`：稳定 ID、标题、说明（可选）、分类 ID、颜色覆盖（可选）、重要/紧急、计划日期、计划时间（可选）、排序键、状态、完成百分比（可选）、完成时间、子任务树、重复/顺延配置、创建/修改时间、来源/历史信息。子任务独立状态/排序；父任务进度可自动按子任务统计或手动设置，最终完成状态明确操作。
- `RecurringRule`：每日、间隔 N 天、每周指定工作日、每隔 N 周、每月指定日期、起止日期/可选结束条件、时区、例外及版本。周期事件实例需**独立状态**；共享的是系列模板/规则而不是每次完成状态。支持单次、从某日之后、未来未完成实例等作用域，不破坏既往已完成记录。
- `CarryForwardTodo`：持续性任务为**同一 ID 和同一完成状态**的跨日展示，而非逐日复制；模式 A：每个未完成/持续日期显示（保留历史日期显示）；模式 B：按天向后移动，仅在最新有效日期显示；保留原始计划日期和移动记录；完成时停止继续向后出现。明确防止同一天产生多份重复显示。
- `Activity`（实际日程）：稳定 ID、标题、emoji（可选）、摘要（短）、正文/备注（可在创建时直接填写，支持纯文本或 Markdown）、心情（可选，多种 emoji 可选）、分类 ID/颜色、一个或多个互不要求相连的 `[start,end)` 时间段、可选 `Todo` 关联、可选周目标关联、修改时间。一个 Todo 可对应多个 Activity，甚至一条 Activity 多个时间段；关联不改变 Todo 完成状态。不同 Activity 可相互重叠。
- `Category`：用户可增删改名称、颜色，预置日常、重要、紧急、工作、生活；重要/紧急可作为醒目标记，并加粗/高亮，但不可仅靠颜色传达含义。待办和实际日程共享分类系统；关联时默认继承分类，可明确独立覆盖。
- `WeekGoal`：所属周（以配置的每周首日计算）、标题/描述/emoji、目标类型（数量/时长/普通勾选）、目标值、自动来源（**待办或日程二选一**，也可无自动来源）、关联的多个 Todo/Activity、自动计算值与可选手动覆盖值、进度/完成状态、显示顺序。允许链接多类对象供导航，但每次计算**只能有一个自动来源**；可变更目标类型及来源，变更时提示统计语义变化，不删除历史关联。
- `WeekReview`：周自由 Markdown、可插入统计摘要和自定义小节；分类耗时、周目标完成情况以及用户自主点评。
- `CalendarDayDecoration`：日期底色（手动选）、节假日、农历、节气、可选黄历宜忌；信息来源与更新时间追踪。
- `AppSettings`：语言、主题颜色、字体颜色/待办背景底色的月历呈现模式、透明度、周首日（周一/周日/其他）、双休日底色、月历模式（按整月/固定行数及上下行页操作）、周计划布局、窗口尺寸/位置/分栏宽度、置顶、贴边、托盘、开机启动、时间轴可见范围、缩放及日历更新等。

窗口偏好还应包含桌面/置顶模式、今日待办折叠状态和两个页面独立的时间轴缩放比例。P1.1 仍只使用模拟业务数据；折叠恢复所需的窗口偏好可以在获批子阶段单独持久化，遵循本地 schema、原子保存与恢复要求，不提前实现 P2 业务数据模型。

数据要求：统一的日期/时间语义、稳定唯一 ID、显式 schemaVersion、可迁移、可备份。删除一条 Activity 不应删除所关联的 Todo；删除 Todo 时保留 Activity（关联变成空或显示历史只读标题，具体交互清楚）；跨天日程存为同一记录并按日裁剪显示。

## 2. 第一页：月历 + 当日待办 + 当日实际日程

### 2.1 左栏月历（较宽）
- 周一至周日七列为默认；设置可改每周首日。包括上月/下月补位日期；上月、下月、回到今天、选年份/月、上一行/下一行或上一页/下一页（依据展示模式）。当前日期和选中日期分别高亮，不刺眼。
- 日期单元格：公历日期、农历（中文显示）、内地与香港节假日明确区分（颜色+标签或图形）、节气、可选黄历宜忌、当天待办文本逐条显示，完成划线变灰；支持单个任务的分类色、字体色/背景标识模式；可为整个日期设自定义底色。
- 单击选中日期，同步更新中栏与右栏；双击日期打开当日待办快速管理界面，可添加/编辑/删除/切换完成。任何空标题的取消都不得误删已有记录。
- 单元格按实际可用高度动态计算完整待办行数，优先保留日期、农历及节假日必要空间；增高尽可能显示更多，缩小时减少，余项显示 `+N`。极小时允许零条正文、只显示 `+N`；不能强制至少一条。避免闪烁、抖动与布局循环，P1.1 使用 0、1、3、10 条模拟数据验证。悬停预览、双击管理及长文字完整查看仍保留在最终范围。
- 每周旁设置周计划：设置可切换**周右侧窄栏**或**每周上下可展开的摘要条**；显示目标及进度，点击可管理。日期视图可展示当天相关周目标的低干扰提醒。

### 2.2 中栏当日待办（相对较窄）
- 顶部显示选中日期、公历星期、农历日期、节气、内地/HK 假日、可用时的宜忌。底部快速输入：可带计划时间 + 文本，回车或 `+` 添加；支持无时间待办。
- 有时间待办默认按时间优先，无时间默认靠后，已完成默认移到末尾；但可手动自由混排有/无时间任务，同级之间拖动/按钮排序；顺序立即持久化。建议提供“恢复按时间排序”命令，不得悄悄覆盖用户手动排序。
- 子任务层级可展开；每个子任务有完成、修改、删除、排序，父任务可显示进度条及百分比，父子任务编辑互不误伤。
- 待办创建/修改：标题、日期、计划时间、分类/颜色、重要/紧急、子任务、进度、周期规则、持续顺延/历史显示模式、关联周目标、复制到其他日期。编辑使用清晰内联或小弹窗，明确保存/取消。
- 取消/删除周期实例时提供：仅本次；从此日期起未来实例；全部未来未完成实例（含已完成实例的保护解释）；整系列若允许应明确风险；不删除历史完成记录。修改周期规则也要提示影响范围。

### 2.3 右栏当日实际日程（相对较窄）
- 第一页右栏与第二页七天区域支持 `Ctrl + 鼠标滚轮` 缩放纵向时间轴；普通滚轮继续纵向滚动。改变每小时像素高度，设合理上下限，尽可能保持鼠标对应时间点的位置；两页独立记忆比例。刻度和日程块位置、高度使用同一比例，不得错位。P1.1 只验证模拟日程。
- 一天 00:00–24:00 的纵向时间轴，默认视口 06:00–24:00，可向上滚到凌晨；显示彩色活动块，按真实时间位置/长度展示，允许同时间并列重叠、可跨天。时间轴滚动、拖拽创建时间段、拖拽移动/缩放时间段；也允许表单输入精确起止时间。
- Activity 可有多个时间段；跨午夜同一记录在多日裁剪显示，修改任一日链接回原始记录。不同时间段累计时可在**同一活动内先合并重叠区间**，避免重复计时。
- 可直接新建独立日程（睡觉、吃饭等），或从待办建立关联日程；关联可以建立在 Todo 完成前、中、后。一个待办可以关联多个时间记录。
- **创建日程当时就提供可选备注**（会议号、链接、文字等），并可选纯文本 / Markdown；不是仅创建后才能写。另有短摘要和可选 emoji；时间块内简洁显示标题、emoji、摘要（截断）；点击展示弹出详情卡片，可查看/编辑完整备注、心情、关联待办/周目标；不设置永久独立便签栏。
- emoji 选择器提供常用类似 reaction 的图标并能搜索/直接输入；心情 emoji 与日程标题 emoji 是不同字段。

## 3. 第二页：周时间轴 + 周计划与周复盘

- 与第一页的所选日期所属周同步；用户可切换前/后周与回本周，切回第一页时日期选择语义明确、不会无提示跳跃。根据“每周首日”设置呈现七天列。
- 七列真实时间轴时间块并列（参考 Outlook 周视图的结构，但更美观），每列与第一页右栏同一 Activity 数据和交互；重叠块并排或堆叠可点击，时间跨度比例正确；跨天段分别展示。支持编辑、复制、移动、创建。
- 右侧周计划与周总结：WeekGoal 新建、编辑、勾选、变更目标类型（数量、时长、勾选）、关联多个待办或多个活动；可在创建待办/日程时选择已有目标或现场新建。
- 自动统计对每个目标只采用**单一来源**（Todo / Activity / 无），且允许手动覆盖进度。数量可按完成的关联待办数量或满足条件的关联 Activity 数量计算；时长按关联实际活动区间计算（裁剪到该周）。数量单位可自定义（篇/次等）。具体进度显示“自动值/手动值”来源可识别。
- 分类耗时：**同一分类内**先按活动时间区间合并去重；不同分类各自独立统计，重叠时间可同时贡献给多个分类，因此分类占比之和允许 >100%。按本周总自然小时数（通常 168 小时；跨 DST 周按当地实际周时长）或明示的统计基准计算百分比，界面标注分母，避免误解；日常总计可另显示全局去重占用时长。周边界要裁剪区间，活动跨周不重复记错。
- WeekReview 默认 Markdown 自由文字，支持插入生成的统计摘要、自定义小节；为用户手动点评提供空间，不把系统统计写死覆盖用户文本。

## 4. 本地 Markdown、图片与备份

- 日程备注支持普通文本和 Markdown，在**创建/修改**时即能选；Markdown 源码编辑与实时预览（不要求 Typora 完全所见即所得），支持标题、强调、列表、表格、代码、链接、本地图片。
- 支持粘贴剪贴板图片自动保存到本地图片目录并插入相对路径 Markdown 引用；也支持选择图片/拖入图片（格式与体积校验）。禁止未经明确请求远程下载图片、脚本执行和任意 `file:`/路径穿越读取。重复粘贴可按安全策略命名；图片引用跨笔记不被误删。
- 例：用户数据根目录默认 `%LOCALAPPDATA%\DesktopCalendar\`（部署/代码目录不是用户数据目录）；`planner-data.json`、`assets/images/`、`calendar-data/`、`backups/`。用户在设置中可打开实际数据目录。不要将真实用户数据提交 Git。
- 所有变更即时可靠保存，原子写入（临时文件+替换/可恢复备份）、数据 schema 验证、损坏保护和错误提示；写入失败不可假装成功。支持 Ctrl+Z 撤销常见编辑/移动/删除操作和必要的重做；对多步修改保证原子撤销。
- 支持软件内一键导出 ZIP（包含 JSON、图片、必要配置/日历资料及版本清单），从 ZIP 恢复前验证文件结构、路径、版本、可用空间，预览影响、备份当前数据，失败回滚；同时说明“退出软件后手动复制整个数据文件夹”可备份。**单独复制 `planner-data.json` 不包含图片，不能算完整备份。**
- 用户隐私：默认不联网，不需登录，只有手动点击日历资料更新或运行更新脚本才访问可信数据源；不上传个人待办、活动、备注或图片。

## 5. 本地日历知识数据与中英文

- 自带离线可用的公历/农历、节气计算或已验证数据、必要年份的内地/HK 假日包；对“中国内地法定放假与调休安排”和“香港公众假期”分别显示来源和最新年份。不能将通用固定节日误称为官方放假安排；尚无官方数据的年份显示“尚未更新/未验证”，不得猜测。可选黄历宜忌；只有数据来源/授权/覆盖年份可验证时才启用，否则清晰标识不可用，不虚构宜忌。
- 设置中的“检查资料更新/下载更新”与独立可运行的更新脚本共用**同一个数据更新模块**，具备来源许可与可信度核验、预览版本/日期范围、校验、缓存、失败回滚和离线兼容。无需联网便可启动/使用软件。
- UI 中文简体 / English 可在设置中切换，尽量即时生效、无需重启；涵盖导航、按钮、编辑表单、设置、托盘菜单、提示、报错、日期格式、周名、分类默认名称、统计用语、节气、节假日官方名称/展示译名、黄历标签（可用时）。**农历日期本身保留中文**；用户自定义待办、日程、分类名称、备注不进行自动翻译。官方中文名称保留为可查看的原名，英文译文由资源表映射，避免机器误译/未验证翻译。资源缺失有明确回退策略，不得直接露出 key。
- 语言切换时窗口自动测量，避免英文过长造成截断或按钮覆盖；文化日期格式与周首日用户设置分别管理（切换语言不擅自改变用户明确设置的周首日）。

## 6. 视觉、窗口及系统行为

- 深色半透明、圆角、低干扰阴影/分隔线；设置背景色、强调色、透明度实时预览，确保浅色与深色壁纸上仍可读。支持月历任务字体色或任务背景色显示、不同周末底色、重要/紧急加粗。
- 两个页面可切换；三栏响应式布局，左栏较宽，中/右栏相对窄且可拖分隔线；窗口四边及四角支持缩放，透明命中区域+正确缩放光标，`BorderThickness=0` 且**没有 Windows 默认白边**；不能用“把白框涂成黑色”充当彻底移除。可拖动窗口、跨屏幕/不同 DPI 正确。
- **默认桌面组件模式（Planned）**：默认不置顶，位于桌面层；Win+D 后仍可见，不像普通窗口一样被最小化，普通应用窗口可以覆盖组件。支持正常点击、编辑、拖动、缩放和切页。
- **任务栏与 Alt+Tab（Planned）**：组件窗口不显示 Windows 任务栏按钮，不进入 Alt+Tab 切换列表；桌面及置顶模式均须满足，不能以破坏输入交互换取排除。两项窗口列表要求与真正的桌面行为分别验证；仅设置 `ShowInTaskbar=false`、隐藏 Alt+Tab 或强制置顶不能作为 Win+D 问题已解决的证据。不得通过定时抢焦点、持续强制修改 Z-order 或反复恢复窗口伪装桌面组件。
- **桌面层技术门槛**：Explorer/WorkerW 仅是待调查候选，未选定方案。先单独验证 Windows 10/11、Explorer 重启、DPI 变化、多屏、休眠恢复与输入交互，再批准整合；不得假设内部窗口机制普遍稳定。有严重兼容风险时提供可复现证据及替代方案，采用高风险内部机制前须明确批准。
- **置顶（Planned 新语义）**：默认关闭；开启切换到置顶悬浮窗口，关闭恢复上述桌面组件行为，保留位置、大小、数据和视图状态；托盘菜单提供置顶开关。
- **今日待办折叠视图（Planned）**：显示今日日期及列表，尽可能保留完成勾选；使用模拟数据，小尺寸随内容合理布局，维持深色半透明圆角，不自动置顶，有清晰按钮恢复完整视图；折叠状态下次启动恢复。旧“—”右上角标签在新模式确认可用后可逐步替换，不要求保留两套机制。
- **托盘（Planned 新语义，2026-10-30 更新）**：默认常驻，作为桌面组件的管理入口；支持双击显示，右键提供“显示/定位组件”“置顶切换”“设置”“退出”。组件自身仍能打开设置并正常退出，不能只能由任务管理器结束。旧“× 必须隐藏到托盘”不再是强制要求；具体关闭按钮行为在实现前明确，保证可找回、可退出及保存语义。
- **宿主失效与安全找回（Planned）**：Explorer 重启或桌面宿主失效后，至少能够通过托盘安全找回组件；Explorer 重启后的托盘入口也须恢复可用，不能依赖已消失的旧图标。找回结果须实际可见、可操作、可退出，不能仅以进程存活或 `visible=True` 判定成功。桌面恢复失败时须明确提示回退状态，不把普通窗口回退标为桌面模式已恢复。
- **贴边**与今日待办折叠是不同功能：左右边缘自动收起为把手，鼠标悬停展开；检查检测、触发条件与 Windows Snap 冲突。优先保证桌面层正确；若不稳定，提出稳定替代交互并取得确认，不得全局关闭 Snap。考虑工作区、多屏、模式互斥与安全恢复。开机自启动开关保留为后续 Planned。
- **Logo 与入口（Planned）**：圆角日历轮廓，少量彩色时间块；深石墨蓝、浅雾蓝主线条、灰绿及柔和紫色。先交付可检查草案/矢量源，确认后制作 16×16、32×32 及较大尺寸 ICO，集成应用和快捷方式；不能以默认 .NET 图标交付。当前用户开始菜单可搜索 `Desktop Calendar`，快捷方式指向稳定可运行位置，不能指向临时构建目录；不未经确认改系统级安装位置。
- 建议优先尝试 C#/.NET + WPF（只面向 Windows），但先做窗口 POC：无白框透明角、缩放、托盘、贴边、多显示器、DPI、资源消耗；若阻碍核心体验，向用户说明证据和替代技术，不得自行大规模换栈。官方 WindowChrome 可参考： https://learn.microsoft.com/en-us/dotnet/api/system.windows.shell.windowchrome 。

## 7. 可用性与性能

- 鼠标操作快捷、点击反馈、空状态清楚、键盘导航与基本快捷键（Enter、Space、Esc、Ctrl+Z 等）；控件尺寸和英文长文案适配。
- 时间轴滚动与拖动保持流畅；大量待办、长 Markdown、附图情况下月历仍可用；不要把所有日期/所有周期实例无限展开。拖拽时间支持对齐粒度和精确编辑；移动时预览新起止时间，放开才提交，撤销恢复。
- P1 人工发现左下/右上角匀速缩小明显抖动，跨 DPI 移动轻微抖动：先定位尺寸、位置修正、最小约束、布局及坐标换算的反馈原因；不得禁用特定方向或降低刷新率掩盖。修复后复验八方向及混合 DPI 跨屏，系统级限制必须说明。
- 日程时间 `[start,end)`，结束需晚于开始（跨午夜允许），零长度拒绝；日期与 DST 边界避免误计。用户所在时区可按系统本地时区显示；储存需要可恢复时间/偏移信息。重复/顺延跨月跨年正确。

## 8. 关键验收案例（最低集）

1. Windows 10/11 实机无默认白边，四边四角缩放无异常，圆角透明且文本可读；高 DPI/多屏位置合理。
2. 月历单击日期同步中/右栏；双击创建、编辑、取消、删除不误删。日期补位、假日标记、节气、农历正确；待办过多 `+N`。
3. 同一持续性 Todo 在多日共享完成；保留历史与仅最新日期两种模式均有效；同一任务不重复生成。
4. 周期性每日待办每天状态独立，删除本次/未来未完成/从本日起实例不影响已完成历史。
5. 有时间/无时间待办自由混排；重启排序保留。子任务独立状态、排序、进度显示正确。
6. 一条 Activity 有多个时间段；跨天 23:00–07:00 在两天分段显示并从任一段打开同一详情；允许不同 Activity 重叠。未完成 Todo 可关联多个 Activity。
7. 创建 Activity 时可填纯文本/Markdown 备注、emoji、摘要、心情；粘贴本地截图立即形成图片引用，预览正确，重启后仍在。
8. 同分类 14–16 与 15–17 应计 3h；不同分类重叠各自独立，百分比可 >100%。跨周只统计落在目标周的部分。
9. 周目标有数量/时长/勾选类型；可关联多条 Todo/Activity，但每目标一次只从一种来源计算；手动覆盖可切换回自动值；新建 Todo/Activity 时可直接建周目标。
10. 菜单、日历术语（节气/节假日名称）、托盘、错误、统计全部可在中英文切换，农历日期仍中文；用户输入不被翻译。
11. 默认断网可正常使用；手动按钮与脚本共享安全更新逻辑，失败保留旧资料；不上传私人数据。
12. ZIP 备份恢复保证 Markdown 图片可见；失败恢复不损坏现有数据；打开数据目录和手动备份说明正确。
13. 桌面/置顶切换、今日待办折叠、默认常驻托盘、左右贴边及自启动的动作明确可复现；托盘右键能显示/定位组件、切换置顶、打开设置及退出。关闭置顶恢复桌面组件行为，切换保留位置、大小、数据及视图；组件自身仍能设置/退出，无未经批准的系统修改。
14. 所有持久化编辑能通过退出/重开确认；删除/拖动撤销合理；JSON 损坏时有备份恢复路径。
15. 分别验证：组件不显示任务栏按钮、不进入 Alt+Tab；默认不置顶时，Win+D 后仍可见且未被最小化，普通应用可覆盖它；点击、编辑、拖动及缩放正常。Explorer 重启或宿主失效后，托盘入口恢复可用并能安全找回实际可见、可操作的组件；休眠恢复、多屏及 DPI 变化后可交互。普通回退不能算作桌面恢复成功，未验证的系统不得声称兼容通过。
16. 折叠视图显示今日日期及待办，不强制置顶，清晰恢复，重启恢复折叠偏好；P1.1 检查仅涉及模拟业务内容。
17. 月历用 0、1、3、10 条模拟待办连续调高/调低，行数与 `+N` 正确，无半行、抖动或布局循环；两页时间轴 Ctrl+滚轮缩放有上下限和独立比例，鼠标时间锚点尽量稳定，刻度与块对齐。
