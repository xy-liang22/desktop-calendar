### P2 实现决定与验证结论

- 采用独立net10.0 Core库和无第三方依赖的控制台测试，不把WPF控件当实体；不可变实体/命令、严格版本DTO映射、存储状态和事务工作区分离。为保留P1.1主程序与安装包，本轮只排除独立目录的默认编译输入，不把Core接入现有模拟UI/窗口生命周期。后续UI添加ProjectReference，通过Workspace命令使用服务，不直接改集合；这是P2允许的接口交付，不宣称业务UI可用。
- 业务JSON schema2；v1为本轮定义的早期迁移合同，不是声称P1曾写业务JSON。版本DTO/默认迁移集中在Codec；更高schema与未知同版本字段禁止覆盖。Options仅为调用上下文，现有独立窗口偏好schema2不改；周首日/时区可注入，历史周身份自身固定，不因设置修改搬移。
- 默认有时间优先；每日期根组/每父节点子组的排序模式单独持久化。手动重排保存键和Manual模式；恢复时间模式不销毁手动键；完成/取消不改任何排序键。关联周期实例先物化祖先；虚拟身份使用文化无关的系列/节点/原始日SHA256派生ID，移动仍保持身份。
- 单次/FromDate/FutureUnfinished/整系列操作有明确命令和日期界限，两种未来范围均保护完成历史；模板版本保存历史，删除模板保留身份墓碑。删除/规则排除未完成实例清理关联但保留Activity及原Todo标题；有完成子节点时保留必要祖先容器，日期树标ContextOnly而不重复计数。已物化实例保留显式日期/树结构例外，新生成实例使用新版本模板。暂停/取消后恢复可通过事务Undo，未提供无限例外预生成或静默删除完成历史。
- 实际时间存DateTimeOffset原偏移＋命名时区，运算按绝对时刻，区间半开；DST空洞拒绝、重复小时需显式偏移。按Windows TimeZoneInfo资料计算，不自带/安装时区数据库。Samoa历史跳日测试最初预期0小时，但本机API给出-10偏移和24小时；证据保留为NOT VERIFIED，并用自有可控时区验证午夜空洞/重复。不能把资料差异算产品通过或擅自更改系统规则。
- 目标实际时长单位秒，对显式关联且裁入所属周的Activity区间取并集；分类各自并集。数量Todo统计所有明确关联的完成项，同时返回跨周警告列表；不静默忽略关联。类型/来源变更须明确确认，关联列表保留；手动覆盖和自动值分开。用户正文与统计快照用不同命令，互不覆盖。
- Category删除语义用归档保留历史分类；内置日常/重要/紧急/工作/生活可幂等初始化，名称提供中英初始值并允许修改。Activity新建/重新关联时默认继承Todo分类，可显式选择独立分类。资产只注册元数据与安全ID引用，不假装已导入/读取图片；日期底色仅数据接口，UI后续接入。
- 同目录独占文件锁、工作区串行队列和文件指纹避免并发/乱序；提交成功才发布内存快照，批量命令一次保存/撤销。Flush/重新解码/Replace和上一版备份；坏原件/备份保留证据，恢复明确确认。UndoRedo限100个会话事务快照，每次保存新Revision，重载清空旧历史；不宣称永久撤销、物理断电或磁盘硬件损坏全部通过。
- 160项数据检查及371项既有WPF回归通过，历史时区资料1项NOT VERIFIED。Win10、混合DPI、Explorer重启/休眠仍沿用P1.1未验证边界，不要求用户重复旧GUI；本轮无UI变化、不重装开始菜单应用。P2完成后停止，等待P3批准。

- WPF `WindowStyle=None`、`AllowsTransparency=True`、透明窗口背景、零原生边框；自身 Border 绘制深色半透明表面，圆角 Clip 防止内容侵入透明角。不是把系统白框涂黑。
- 透明度只作用于背景笔刷，不对整窗设置 Opacity，以保持文字对比度。默认背景 96%；没有引入 Acrylic/Mica、第三方主题库或改变 Windows 设置。
- 八个 WPF Thumb 负责缩放与光标；采用 DragDelta 的 DIP 位移，经当前 HWND DPI 转为物理像素。窗口定位、紧凑位置、跨屏恢复和工作区判断统一使用物理像素。避免在拖拽事件中另行轮询系统鼠标造成输入流不一致。
- 使用 PerMonitorV2 manifest。项目的 WinForms 引用仅用于系统托盘及显示器信息；局部抑制 `WFO0003`，因为这是 WPF 的 DPI 初始化，不是 WinForms 主应用。未忽略其他编译警告。
- 展开、紧凑、贴边把手、托盘为互斥状态；保存的是展开状态的矩形。从任意隐藏状态恢复均返回展开窗口；托盘与紧凑状态不触发贴边计时。置顶开关独立保留。
- 贴边采用缩成窄把手，而非把完整窗口移动到另一显示器的画面中；恢复位置会按当前可用工作区约束，支持显示器移除后的安全回退。
